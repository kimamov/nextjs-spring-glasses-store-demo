# Project instructions

## Learning workflow

For each new implementation request:

1. Help the user clarify and restructure the request before making changes.
2. Agree on the scope and essential acceptance criteria with the user.
3. Wait for the user to rewrite the agreed request in their own words before executing it.
4. Implement the rewritten request and report relevant verification results.

Keep this process concise. Ask only essential questions, avoid lengthy templates,
and do not repeat the process for routine follow-ups within an agreed task.
Answer informational questions directly.
